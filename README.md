# my-tools
雑多なツール群

## 方針
- 複数ツールを1リポジトリで管理する
- 各ツールは段階的に開発する（要件 → 設計 → 実装）
- 可能な限り Copilot で作成する

## ディレクトリ構成
```text
working-time-calculator/
	requirements/   # 要件定義
	design/         # 設計
	implementation/ # 実装・テスト
		src/
		tests/
```
