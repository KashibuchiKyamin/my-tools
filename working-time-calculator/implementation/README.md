# 稼働時間計算 - 実装

このフォルダには、実装コードとテストを配置します。

- `src/`: 本体コード
- `tests/`: 簡易テスト（必要に応じて）

## 実装ファイル
- `src/index.html`
- `src/style.css`
- `src/app.js`

## 起動方法
- `src/index.html` をブラウザで直接開く

## MVP実装済み機能
- 休日CSV読込（重複日付チェック、対象月外無視）
- 勤務CSV読込（単月チェック、全置換）
- 計算ボタンでの日次・月次集計
- 差分表示（実績合計 - 15分丸め合計）
- 着地予想（固定8.0時間）
- 勤務CSVエクスポート
