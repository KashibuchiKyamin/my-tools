2. 対象月の指定方法はどれにしますか？
   - [ ] `input type="month"`
   - [ ] 年・月のプルダウン
   - [x] その他
   - 回答:勤務CSVを読ませたら、勤務CSVの月を対象月とする。

3. 勤務入力はどの単位で行いますか？
   - [ ] 手入力で行追加
   - [ ] 対象月の稼働日を自動行生成
   - [ ] 両方
   - 回答:表形式で当月のすべての日が入力欄として用意してあり、そこに入力をする。

4. 1日の入力項目は以下で確定ですか？
   - 日付 / 開始 / 終了 / 休憩（分）
   - 回答:OKです。すべてhh:mmで入れたいです。

5. 入力値を編集したとき、集計値の更新タイミングは？
   - [ ] 入力のたびに即時計算
   - [x] 「計算」ボタン押下時
   - 回答:計算は、以下のようにお願い致します
     - 当日分の休憩時間を除いた時間を算出し、総労働時間hh:mm、総労働時間15分単位で四捨五入hh:mm、15分単位四捨五入を少数表記したもの(09:15ならば09.25)
     - それぞれの和を算出する
     - 15分単位四捨五入によって、ズレる。これは勤務先の勤怠が15分単位で管理しているためである。自社は1分単位なのでずれているが、最終的にその月の総労働時間が一致していれば良いので、最終日に勤務時間を切りの良い時間になるようにすることで対応している。※すれている状態であることがわかるようになっている必要がある。

6. エラー表示の粒度は？
   - [x] 画面上部に一覧のみ
   - [ ] 各行にもエラー表示
   - [ ] 両方
   - 回答:何日の部分でエラーになっているのかはわかるとよい。
